# Serverless-Architecture_HeroVired-Assignment
HeroVired Assignment on Serverless Architecture using AWS Lambda and Boto 3

## Assignment 1: Automated Instance Management Using AWS Lambda and Boto3
Objective: In this assignment, we will gain hands-on experience with AWS Lambda and Boto3, Amazon's SDK for Python. We will create a Lambda function that will automatically manage EC2 instances based on their tags.

Please find the details Assignment 1 readme file and the python lambda function code in the Assignment 1 folder `Assignment 1 >> Assignment 1.md >> lambda_function`

## Assignment 2: Automated S3 Bucket Cleanup Using AWS Lambda and Boto3
Objective: In this assignment, we will gain experience with AWS Lambda and Boto3 by creating a Lambda function that will automatically clean up old files in an S3 bucket.

Please find the details Assignment 2 readme file and the python lambda function code in the Assignment 2 folder `Assignment 2 >> Assignment 2.md >> lambda_function`

## Assignment 3: Monitor Unencrypted S3 Buckets Using AWS Lambda and Boto3
Objective: In this assignment, we will enhance AWS security posture by setting up a Lambda function that detects any S3 bucket without server-side encryption.

Please find the details Assignment 3 readme file and the python lambda function code in the Assignment 3 folder `Assignment 3 >> Assignment 3.md >> lambda_function`
