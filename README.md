# Serverless-Architecture_HeroVired-Assignment
HeroVired Assignment on Serverless Architecture using AWS Lambda and Boto 3

## Assignment 1: Automated Instance Management Using AWS Lambda and Boto3
Objective: In this assignment, you will gain hands-on experience with AWS Lambda and Boto3, Amazon's SDK for Python. You will create a Lambda function that will automatically manage EC2 instances based on their tags.

Please find the details Assignment 1 readme file and the python lambda function code in the Assignment 1 folder `Assignment 1 >> Assignment 1.md >> lambda_function`
